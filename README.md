## Реалізація патерну Singleton (TypeScript)

У папці `src/creational/singleton` реалізовано породжуючий патерн **Singleton (Одинак)**. 
Він гарантує наявність лише одного екземпляра класу в системі за рахунок:
1. Приватного конструктора.
2. Статичного поля для збереження об'єкта.
3. Статичного методу `getInstance()`.

### Як запустити приклад:
1. Встановити залежності: `npm install`
2. Запустити демонстрацію: `npm run singleton`
